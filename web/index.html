About HuStringSearch

HuStringSearch explores protein interaction networks by merging interactome sources and running a Random Walk with Restart (RWR) centered on a gene of interest, returning the proteins most closely connected to it.

  • Merged interactomes: combines HuRI (experimental binary map) with STRING confidence-scored associations, and can add BioGRID, IntAct, or your own edge lists.
  • Shared identifier space: proteins are mapped to Ensembl Gene IDs, with species-general support (any NCBI taxon), so sources merge cleanly.
  • Target-centered subnetworks: ranks every node by network proximity to the target(s) and extracts a subnetwork by top-k, score threshold, or k-hop.
  • Interactive viewer: search a gene, tune the walk, and explore the resulting network, ranked partners, and edge weights.
  • Runs anywhere: locally through the CLI or this browser UI, or hosted from a single Docker image.

Current build: merged Human HuRI + STRING network. Additional species and sources are supported by the build pipeline.
